Anchor (working name) is a menu-bar-only macOS app at `~/projects/anchor` (SPM executable, macOS 14 floor, conventions lifted from [[onething-app]]). One toggle: while LOCKED you're pinned to the window frontmost at lock time, and to the active tab if it's a browser (Safari, Chromium family, Arc, Dia).

Key decisions (confirmed 2026-07-17): block + snap back enforcement (CGEventTap swallows shortcuts/clicks; FocusWatchdog AX-raises anything that slips through), hold-to-unlock ~3 s in a non-activating FloatingPanel, Cmd+Q/Cmd+W blocked while locked, Ctrl+Cmd+Q (lock screen) deliberately never blocked. Failsafes: menu bar strip always clickable (dead-man rule checked before any cache), hold Esc 5 s force-unlock inside the tap callback, lock state never persists across launches.

Empirical browser probe results: Dia tab `id` is a stable UUID, `active tab` works, revert via `focus` command (verified live; better than OneThing-era notes). Arc: `select` exists in sdef but revert iterates tabs and selects by matched id (string-id specifiers are fragile); degrades to window-only lock on script error. Safari: no tab id — index + lastKnownURL tracking. Dia bundle id: `company.thebrowser.dia`.

ChromeGuard (browser locks): clicks on the locked browser window are only allowed inside the AXWebArea rect (0.5 s AX tracking) — kills URL-bar, tab-strip, and sidebar mouse paths; fuzzy-bounds match so browser sheets/dialogs stay clickable; degrades to whole-window if AXWebArea isn't found. Cmd+S/L/Shift+L/O/K added to browser-blocked. Dia/Arc sidebar auto-collapses at lock via synthetic Cmd+S (sentinel in eventSourceUserData so the tap passes it) only when content-offset heuristic says it's open.

Iconography: Phosphor icons (user preference over SF Symbols), vendored as raw SVG path strings in `PhosphorIcons.swift` with a hand-rolled SVG-path→SwiftUI Shape parser (M/L/H/V/C/S/Q/T/A/Z, arc→bezier) — the official phosphor-icons/swift SPM package is unusable without full Xcode (needs actool for its xcassets). Menu bar icons rasterized via ImageRenderer (unlocked=template black, locked=orange baked). Add icons by pasting the `d` string from @phosphor-icons SVGs. Icons visually verified via ImageRenderer→PNG smoke test.
